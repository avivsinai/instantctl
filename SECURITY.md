# Security policy

`instantctl` handles account credentials and can change network configuration.
Do not include passwords, tokens, private API responses, device identifiers, or
private network details in public bug reports.

To report a vulnerability, use **Security → Report a vulnerability** on this
GitHub repository when private vulnerability reporting is enabled. Do not open
a public issue for an unpatched security problem. If private reporting is
unavailable, contact the repository maintainers through GitHub and ask for a
private reporting channel.

Security reports should describe the affected version or commit, the impact,
and steps to reproduce with synthetic data. Redact credentials and private
account details from logs and attachments.
