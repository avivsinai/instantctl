# Code of conduct

We want a respectful and useful community for everyone. Treat people with
respect, discuss ideas in good faith, and focus criticism on the work rather
than the person.

Harassment, discrimination, threats, personal attacks, and sharing private
information without consent are not acceptable. Follow the rules of the GitHub
spaces where this project is hosted.

If you experience or witness conduct that conflicts with this policy, contact
the repository maintainers through GitHub. They will review reports and decide
what action is appropriate for the project space.
